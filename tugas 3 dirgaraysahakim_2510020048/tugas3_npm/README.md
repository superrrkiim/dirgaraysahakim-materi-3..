# Tugas Mandiri Pertemuan 3 — Formulir & Data

Mini-situs HTML untuk mata kuliah Pemrograman Web 1.

## Isi folder
- `data.html`: tabel data mahasiswa dengan caption, thead, tbody, tfoot, colspan, dan rowspan.
- `form.html`: formulir pendaftaran UKM dengan berbagai input type, label, fieldset, legend, select, textarea, validasi bawaan, submit, dan reset.
- `style.css`: tampilan responsif.

## Cara menjalankan
Buka `data.html` atau `form.html` menggunakan browser.

## Catatan
Data nama dan NPM di `data.html` adalah data contoh. Ganti dengan data yang diizinkan dosen bila diperlukan. Form belum terhubung ke backend; tugas ini berfokus pada struktur dan validasi HTML.
